# List of documentation available

The following table of documentation links provide a comprehensive, curated index of essential links designed to guide Virtual Infrastructure (VI) Administrators and Platform Administrators through each stage of the Kubernetes Platform deployment. By following this structured roadmap, administrators can quickly identify key requirements, prerequisites, and operational guidelines across all phases. Note that the resources referenced here represent specific snapshots within the broader ecosystem; for complete specifications and advanced configurations, refer to the primary parent categories: vSphere Supervisor Administration, Service Administration and Management, Consumption, VCF Automation, and Consumption APIs.

Phase 1: Supervisor Deployment based on Network and Load Balancer  
Phase 2: Harbor Service Registration & Install (Required for Software Depot deployments in 9.1.1+)  
Phase 3: Airgapped Procedures by VCF Version (Skip if internet connected)  
Phase 4: Argo CD Service Registration & Install(Optional)  
Phase 5: Prepare the Platform for Consumption  
Phase 6: Deploy workloads and runtimes (VKS, Argo CD)  
Phase 7: Upgrade of Supervisor , VKS, or VKS Clusters   
Phase 8: Backup and Restore of Supervisor or VKS Clusters  
Phase ∞: General everyday documentation
